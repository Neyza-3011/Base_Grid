# Project Guidelines & Context

This repository contains the full-stack codebase for **Rapportini B2B Enterprise**, a multi-tenant SaaS platform for construction, plumbing, and electrical companies.

## Architecture Highlights

- **Frontend**: React 18, Vite, TanStack Router, Tailwind CSS, Lucide Icons.
- **Backend**: FastAPI (Python), Async SQLAlchemy 2.0, PostgreSQL, Redis rate limiting, JWT + Google OAuth, Stripe Billing, and Super-Admin Control Panel with Sandbox environment.
